Drag files onto the remote screen to send them. With this on, the file is pasted straight into whatever you dropped it on (a chat, an email, a folder) — no operating system lets an app fake a true drop, so it goes via the clipboard as a file, exactly as if you had copied it there. With it off the file is just placed on the remote clipboard for you to paste yourself. Either way a copy is saved to your Downloads folder.
Connecting out
A host's password is asked once and remembered (unless you untick "Remember" when asked), so connecting again needs no typing. Saved passwords belong to the account in use, are encrypted for your user account on this computer, and are only kept after they have actually worked.
