# L10 — XDG autostart (Linux tester checklist)
1. Ubuntu 22.04/24.04: turn "Start at login" on, sign out and back in; the app starts minimized, and `~/.config/autostart/sharectrl.desktop` has `Exec=<absolute path> --autostart`.
2. Run the AppImage from another folder with the setting on, move the file, restart the app: the entry is re-pointed at the new path; turning the setting off deletes `sharectrl.desktop`.
3. Turn the entry off in GNOME Startup Applications, restart the app, and confirm it stays off (`X-GNOME-Autostart-enabled=false` is kept).
4. Run the deb build from a terminal inside another AppImage, turn the setting on: the Exec line shows `/usr/bin/sharectrl`, not the other AppImage.
