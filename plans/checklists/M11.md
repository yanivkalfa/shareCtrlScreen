# M11 — macOS permissions preflight (tester checklist)

Needs: a Mac (13+, ideally also 15) and a **fresh user account** (System Settings -> Users &
Groups -> Add User; no prior grants for ShareCtrlScreen). Run the signed test build, with the
D5 preflight modal if it has landed; otherwise log `Platform::permissions()` (the report is
what is checked).

How to read the report: a permission that is not granted reads `NotDetermined` until the
app itself has asked once in this launch, then `Denied`. macOS cannot tell "never asked"
from "refused" (see `platform-macos/src/permissions.rs` docs). The Screen Recording note
about the monthly renewal is always present.

| Step | Action | Report must say |
|---|---|---|
| 1 | Launch as the fresh user | screen_capture, input_injection, input_monitoring all `NotDetermined`; notes about monthly re-approval and "Keyboard shortcuts need two switches" present |
| 2 | Request Screen Recording | macOS prompt "would like to record the screen" appears. Meanwhile state stays `NotDetermined`/`Denied`, never `Granted` |
| 3 | Click "Open System Settings" in that prompt (or dismiss, then request again) | Request again opens Settings -> Privacy & Security -> **Screen & System Audio Recording** directly |
| 4 | Enable ShareCtrlScreen there; macOS asks to quit & reopen; reopen | screen_capture `Granted` (it only flips after a restart) |
| 5 | Request Accessibility | system dialog with "Open System Settings"; state `Denied` on next poll; requesting again opens the **Accessibility** pane |
| 6 | Enable it | input_injection `Granted` with no restart, within a poll or two |
| 7 | Request Input Monitoring | prompt appears; requesting again opens the **Input Monitoring** pane |
| 8 | Enable it | input_monitoring `Granted` (may need restart). It needs Accessibility too (since M6), which step 6 already granted; the "two switches" note disappears |
| 9 | Disable Accessibility again | input_injection **and** input_monitoring return to `Denied` (not `NotDetermined`) in the same launch |
| 10 | Open Terminal, `Secure Keyboard Entry` on (Terminal -> Secure Keyboard Entry), poll | notes gain the "Secure Input is active" line; off again -> line disappears |
| 11 | (macOS 15) wait for or force the monthly prompt | not testable on demand; confirm only the note text |
| 12 | Quit and relaunch after refusing something in step 2 | that permission reads `NotDetermined` once; first request silent; next poll `Denied`; next request opens Settings (expected, documented) |

Report back: macOS version, chip, and any step where the pane opened was the wrong one or a
prompt appeared on a probe (probes must never prompt).
