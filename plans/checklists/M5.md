# M5 — macOS CGEvent input injection (tester checklist)

Needs: a Mac (13+, ideally also 14 or 15 for the activation rules), ideally with a **second
display** arranged left of or above the main one (negative coordinates), and a Windows (or
second Mac) viewer for the session steps. The Mac is the **host**. Code:
`platform-macos/src/{injector,inject_state,focus}.rs`.

## Part A — device tests (Terminal on the Mac, no viewer needed)

Grant Accessibility to Terminal (System Settings > Privacy & Security > Accessibility), then
from `native/`:

```text
cargo test -p platform-macos --test inject_smoke -- --ignored --nocapture --test-threads=1
```

| Step | Test | Pass when |
|---|---|---|
| A1 | `pointer_reaches_every_display` | passes (asserted): the pointer reaches the corners and centre of every display, the main one through both `None` and its rect |
| A2 | `types_hello_then_cmd_v_pastes` (click into an empty TextEdit document during the countdown) | TextEdit reads `hello world` |
| A3 | `release_all_leaves_no_modifier_held` (caret at the end of the text) | the text ends in a lowercase `a`; nothing is selected |
| A4 | `focus_window_at_activates_the_window_under_the_point` (Finder active, pointer resting on TextEdit) | TextEdit becomes active (menu bar says TextEdit); the caret did not move |
| A5 | Revoke Terminal's Accessibility, run A1 again | it fails at once with "grant Accessibility … System Settings > Privacy & Security > Accessibility" (no silent pass) |

## Part B — a real session (installed app, viewer on another machine)

Give ShareCtrlScreen Accessibility first. Expected behaviour is "like AnyDesk".

| Step | Action on the viewer | Expected on the Mac host |
|---|---|---|
| B1 | Before granting Accessibility: start a control session | session runs view-only; the viewer sees the toast "Remote control is unavailable on this computer: … Accessibility …" |
| B2 | Grant it, reconnect; move the mouse over the whole picture | the Mac pointer follows exactly, including the far right/bottom edge; on a Retina display no offset or 2× drift |
| B3 | Share the **second** display (Settings → share display), repeat B2 | pointer stays on that display and matches the picture |
| B4 | Click, double-click a word, triple-click a line in TextEdit | single click places the caret; double selects the word; triple selects the line |
| B5 | Drag a Finder icon, drag-select text, right-click, middle-click in a browser tab | drag moves/selects; context menu appears; middle-click opens/closes per the app |
| B6 | Type `Hello, World!` with Shift; Ctrl+A / Cmd+A; Option+E then E | text exact; shortcuts act; dead key gives `é` |
| B7 | Caps Lock on, type `abc`, Caps Lock off, type `abc` | `ABCabc`; the Mac's own keyboard afterwards still types normally |
| B8 | Hold a letter key | it repeats at the viewer's repeat rate |
| B9 | Scroll with a mouse wheel (one notch at a time), then a trackpad, both axes | one notch ≈ 3 lines (≈ 40 px in Safari/Chrome); horizontal goes the same way as on the viewer; slow trackpad scrolling still moves |
| B10 | Hold Shift + Cmd and a mouse button, then disconnect the viewer (kill its network) | after the session drops, the Mac's own keyboard types lowercase without Cmd and no button is stuck (no drag on next local move) |
| B11 | While a remote user moves the mouse continuously, move the Mac's own mouse | the local mouse still works (no 0.25 s lockouts) |
| B12 | Drop a file from the viewer onto a TextEdit window that is **behind** another app's window, and onto the second of two TextEdit windows | that exact window comes forward and the file is pasted there (Cmd+V); repeat on macOS 14/15 |
| B13 | Revoke Accessibility mid-session | remote input stops; the host log shows "Accessibility was revoked …" within ~2 s; re-granting resumes it with a log line |
| B14 | Viewer is a Mac with shortcut capture on (once M6 lands) | the host Mac's own event tap does not echo our injected keys back |

Report back: macOS version, chip, display arrangement (and scales), and every step that
differs, especially B4 (click counts), B7 (Caps Lock via flags), B9 (scroll distance and
direction) and B12 (activation on 14+).
