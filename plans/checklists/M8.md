# M8 — Keychain secret store (device check)

1. On a Mac, in `native/`: `cargo test -p platform-macos -- --include-ignored`. It writes and deletes real Keychain items under service `dev.netameta.sharectrl`; click "Always Allow" on any Keychain prompt.
   Expected: `test result: ok. 5 passed; 0 failed; 0 ignored` (round-trip, unknown id gives `None`, deleted item gives `None`, id format, garbage rejection).
2. Locked keychain: lock the login keychain (`security lock-keychain`), run the round-trip test, and cancel the unlock dialog. The test fails and the warn log names the cause. It does not fail on its own; it waits for the dialog.
3. In the app, tick "Remember password" for a host, then copy that host's value from `saved_logins` in `~/Library/Application Support/ShareCtrlScreen/config.json` (the id). Run `security find-generic-password -s dev.netameta.sharectrl -a <id>`: it lists the item, and the `config.json` value on its own is only the id, not the password.
4. Clear the saved logins in the app (forget the host). Run the same `security find-generic-password -s dev.netameta.sharectrl -a <id>` again. Expected: it now fails with "could not be found", because `forget` deleted the item.
